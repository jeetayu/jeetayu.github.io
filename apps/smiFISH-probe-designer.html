Repeat / low-complexity masking

Rejects candidate windows that look like simple tandem repeats or low-complexity sequence (DUST-style triplet-frequency score). This is a lightweight in-browser approximation of RepeatMasker — it catches homopolymers and simple/tandem repeats but not interspersed repeats (Alu/LINE/SINE), which need a real repeat database. For intronic probes crossing repeat-rich sequence, cross-check candidates against the UCSC RepeatMasker track before ordering.

Secondary structure (hairpin ΔG)

Scans each probe for self-complementary stem-loops and estimates hairpin ΔG at 37°C using the same nearest-neighbour table as the Tm calculation, plus an approximate loop-initiation penalty (SantaLucia & Hicks 2004). This is a simplified two-state estimate, not a full partition-function fold (mfold/OligoArrayAux/UNAFold) — treat borderline probes as flagged for manual follow-up, not automatically safe.

Readout (RO) handle sequences

Select RO sequences to append to probe 5′ and 3′ ends. All probes in a set use the same RO pair.

3 — Specificity / Off-target Screen

The local search step Oligostan normally does with BLAST. Each candidate probe's target window is compared against background sequence(s) by sliding-window identity; probes that closely match a background sequence are flagged as likely cross-hybridising and excluded by default. This does not replace a full transcriptome BLAST/Bowtie search before ordering, but it catches the single most common failure mode for paralogue-rich gene families (e.g. X–Y gametologs): a probe that looks perfect in isolation but also binds a near-identical paralogue transcript.

Ordering Tips

  • Order as standard desalted DNA oligos, 25 nmol scale.
  • For <20 probes use IDT or Sigma individual oligo ordering.
  • For ≥20 probes use IDT plate format (save ~70% cost).
  • RO readout probes labelled with Cy3/Cy5 can be purchased from IDT or synthesised in-house.
  • Before ordering, run flagged/borderline probes through a real transcriptome BLAST/Bowtie search (this tool's specificity screen only checks fetched paralogues + any pasted background, not the whole transcriptome/genome) and a full fold predictor (mfold/OligoArrayAux/IDT OligoAnalyzer) to confirm the hairpin call.
  • See Tsanov et al. 2016 for full smiFISH protocol.
